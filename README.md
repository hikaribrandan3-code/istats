# iStats

Free native macOS system-monitoring app built with Swift, SwiftUI, and AppKit. It displays live CPU, memory, network, and disk readings with rolling charts and top process lists.

- macOS source and build notes: [`macos-source/`](macos-source/)
- Requirements: macOS 14 or later
- Current release status: source is public; no compiled app download is published yet

The app reads system metrics locally. The source README lists current features and limits.
