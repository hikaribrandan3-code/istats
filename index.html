Features

A focused view
of your Mac.

◈

Dashboard and menu bar

See CPU, memory, network, and disk in a dashboard window. The menu-bar icon provides a quick way to reopen or quit the app.

◉

Live Graphs

Swift Charts keep the latest 60 samples. Memory is an estimate, and network rate shows one named interface.

◎

100% Offline

All monitoring happens locally using native macOS APIs. No network calls, no data collection, no cloud. Your system info stays on your system.

◐

Adjustable refresh

Choose a one, two, or five second refresh interval in Settings.

Frequently Asked Questions

How much does iStats cost?
iStats is free. The source is public; a compiled download is not published yet.
Does it work on Intel Macs?
iStats requires macOS 14 or later. The current app package was built on Apple Silicon; Intel compatibility has not been verified.
Does iStats collect any data?
Absolutely not. iStats runs entirely on your Mac using native system APIs. No network calls, no telemetry, no accounts required. Your system data never leaves your machine.
Can I use iStats with iSuite Office?
Yes. iStats is part of the iSuite family, alongside iBrain and other standalone Mac apps.
